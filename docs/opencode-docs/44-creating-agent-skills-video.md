# Создаём Agent Skills — стенограмма и методология

> **Видео:** https://www.youtube.com/watch?v=Lyp5LUFaZDA  
> **Канал:** Нейропросвещение  
> **Инструмент:** OpenCode (V4 flash free)

Пошаговый разбор создания Agent Skill с нуля: от промта до готового SKILL.md со скриптами, референсами и ассетами.

---

## Что такое Skill

Skill — это та же директория с файлами в строго определённых местах:

```
skill-name/
├── SKILL.md          ← основной файл (обязательный)
├── scripts/          ← исполняемый код
├── references/       ← документация
└── assets/           ← шаблоны, примеры, картинки
```

Обязателен только `SKILL.md`. Остальное — опционально.

В шапке SKILL.md — YAML frontmatter с как минимум двумя полями:

```yaml
---
name: hacker-news-digest
description: "Получает и анализирует свежие новости с Hacker News"
allowed-tools: Bash, Read, Write, Grep, Glob
---
```

- `name` — имя скилла
- `description` — описание (матчится с запросом пользователя)
- `allowed-tools` — **ограничение инструментов** (опционально, но повышает безопасность)

---

## Зачем Skills

Работа с агентом — это управление контекстом. Проблема:

- Контекст ограничен
- Непонятно что класть, что не класть
- Раньше люди собирали коллекции промтов на все случаи жизни

Skills решают это через **progressive disclosure**: в начале каждой сессии загружается только `name` + `description` (короткая строчка). Полный SKILL.md подгружается **только когда skill активирован** — по прямому вызову или по совпадению description с задачей.

## Методология создания (шаги)

### Шаг 1. Опиши проблему

Не начинай со структуры скилла. Начни с промта:

```
Получи новости с Hacker News API за последние сутки.
Выбери самые актуальные.
Верни краткий пересказ в 2-3 предложения на каждую.
```

Запусти в агенте. Посмотри что получится.

### Шаг 2. Итеративно уточняй вывод

Правишь промт по результату, пока вывод не устроит:

```
- Используй только newstories, не topstories
- Убери группировку по категориям
- Добавь рейтинг и количество комментариев
- Убери английские заголовки
- Оставь только новости с рейтингом > 1
```

На этом этапе **не оптимизируй производительность**. Сначала добейся формата вывода.

### Шаг 3. Упакуй в SKILL.md

Когда формат устраивает — проси агента сформировать SKILL.md по спецификации [agentskills.io](https://agentskills.io).

Ключевые моменты для включения в промт:

- Вынести загрузку данных в **отдельный скрипт** (чтобы не ходить в сеть через агента)
- Запросы делать **параллельно** в скрипте, не последовательно
- Сохранить **пример отчёта** в `assets/`
- Скрипт должен возвращать **структурированные данные** (JSON)

### Шаг 4. Проверь и доработай

Сбрось сессию, перезапусти агента, вызови скилл:
```
/hacker-news-digest
```

Оцени скорость, качество, расход токенов.

### Шаг 5. Добавь функциональность

Пример: после вывода списка предложить выбрать новость для детального разбора.

Пиши новым промтом:
```
После вывода списка новостей допиши "Введи номер новости чтобы узнать больше".
Когда выбрана — загрузи комментарии, подготовь развёрнутое summary.
```

### Шаг 6. Сделай ревью скилла

Попроси агента:
```
Пересмотри тред и найди что нужно исправить в описании скилла
или структуре после добавленного нового этапа.
Только найди, не меняй без разрешения.
```

Типичные проблемы: нет примера в ассетах, слишком длинные строки, не обработаны граничные случаи.

## Результат

В видео: скилл Hacker News Digest, который:

- Загружает новости через скрипт (параллельные запросы, а не последовательные)
- Показывает отфильтрованный дайджест
- Позволяет выбрать новость для глубокого разбора
- Загружает комментарии и готовит развёрнутое summary
- Работает **быстрее и дешевле** чем без скилла (тратит меньше токенов)

И всё это — на V4 flash free в OpenCode.

## Ключевые принципы

1. **Не усложняй.** Skill = промт в папке. Не делай из него фреймворк.
2. **Автоматизируй рутину, а не принятие решений.** Агент выполняет, человек утверждает.
3. **Сначала формат, потом производительность.** Сначала добейся правильного вывода, потом оптимизируй скриптами.
4. **Выноси запросы в скрипты.** Это экономит токены и ускоряет работу.
5. **Делай ревью скилла.** Агент сам найдёт что упущено.
6. **Skills не должны засирать контекст.** Если скиллов много — их описания начинают отвлекать модель.
